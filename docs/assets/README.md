# Public demo assets

These five JPEG stills are student-recorded staged activity-recognition demonstrations supplied for public portfolio use. They show pose-detection overlays and model labels for the following activities:

- Open fridge
- Open bedside table drawer
- Lay on bed
- Sit on couch
- Sit at table

They are demonstrative outputs only. Do not use them as clinical evidence, infer model accuracy from them, or add raw videos, training data, participant names, or additional participant imagery without verified consent.
